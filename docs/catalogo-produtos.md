## Como Consultar Produtos

Para encontrar um produto específico:
1. **Por código**: Informe o código de referência (ex: "produto 8520")
2. **Por nome**: Descreva o produto (ex: "conjunto brilho")
3. **Por categoria**: Escolha a categoria (ex: "sutiãs", "baby dolls")
4. **Por preço**: Informe faixa de preço (ex: "produtos até 50 reais")
5. **Por estoque**: Verifique disponibilidade (ex: "tem estoque de tanga 216?")
